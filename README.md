# Safety First Service Tracker

Modern Web Application for tracking Customer Details, Service Center Entries, and Return Status.

## 🚀 Quick Start (One-Click Launch)

This project is designed for ease of use. You do not need to manually start databases or servers.

1.  **Install Python**: Download and install Python from [python.org](https://www.python.org/). (Ensure you check **"Add Python to PATH"** during installation).
2.  **Install MariaDB**: Ensure MariaDB 12.2 is installed in the default location (`C:\Program Files\MariaDB 12.2`).
3.  **Run the App**: 
    *   Simply double-click **`Launch_Service_Tracker.bat`**.
    *   The script will automatically:
        *   Start the MariaDB database if it's not running.
        *   Create the necessary database and tables.
        *   Install any missing software dependencies.
        *   Open the application in your browser at `http://127.0.0.1:5000`.

## ✨ Key Features

*   **Automated Management**: No manual database configuration required.
*   **Safe Exit**: Closing the application only stops the tracker; it will not interfere with other Python programs on your computer.
*   **Customer Entry**: Log customer complaints and details seamlessly.
*   **Service Tracking**: Track items sent to service centers with DC (Delivery Challan) generation.
*   **Smart Reports**: 
    *   Pending Reports (track items currently at service).
    *   Status Reports (comprehensive history).
    *   Export to CSV/Excel for all reports.

## 🛠️ Technical Info

*   **Backend**: Flask (Python)
*   **Database**: MariaDB 12.2 (SQLAlchemy)
*   **Frontend**: HTML5, Vanilla JS, CSS3 (Premium Responsive UI)
